# /init

Re-run project bootstrap for this repo.

## What this does

1. Verify git is initialized and `origin` points to `predator-1-ml/hackathon`
2. Confirm local git identity is set for this folder only (not global)
3. Scaffold missing baseline files (`README.md`, `.gitignore`) if absent
4. Report status and next steps

## Usage

Run this command when opening the project in a fresh clone or after changing remotes.
